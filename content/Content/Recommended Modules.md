The following are the modules I would always install in every instance of GGA:

- **Dice So Nice!** - A module that makes dice rolls visible as 3-D models.
- **GURPS Token Shape and Movement** - Useful for non-single hex tokens and showing GURPS facings (Front, Sides, Rear).
- **Token Action HUD GURPS** - Popup shortcuts for rollable traits and values for a token.
